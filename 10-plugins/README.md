# Section 10 — Plugins

> Status: **coming in v1.3**

Plugins bundle commands, skills, hooks, and subagents into a distributable package. Planned labs:

- `lab-01-install-a-plugin` — install a plugin from the sandbox marketplace.
- `lab-02-author-a-plugin` — bundle a slash command and a skill into a distributable plugin.
- `lab-03-publish-to-marketplace` — write the `marketplace.json` manifest and validate it.
