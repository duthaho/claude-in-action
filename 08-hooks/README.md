# Section 08 — Hooks

> Status: **coming in v1.2**

Hooks are shell commands that fire on Claude Code events (pre-tool, post-tool, session start, etc.). Planned labs:

- `lab-01-pre-commit-hook` — block commits that still contain `TODO` markers.
- `lab-02-post-tool-logger` — log every `Edit` tool call to a file.
- `lab-03-safety-hook` — deny writes to a `prod/` directory.
