# Starter — lab-01-filesystem-mcp

The starter has two subdirectories:

- `docs/` — three sample files you want Claude to see through MCP.
- `secrets/` — a fake credential you do **not** want Claude to see.

Your job is to author `.mcp.json` so the filesystem server is scoped to `docs/` only. See the lab README one level up for the full steps.
