# Starter — lab-02-sqlite-mcp

The database is **not** pre-built on disk. Build it:

```bash
python build_db.py
python inspect_db.py   # see schema and sample rows
```

Then author `.mcp.json` to wire a SQLite MCP server against `library.db`, and write `queries.md` with five natural-language questions plus the tool each one uses. See the lab README one level up.
