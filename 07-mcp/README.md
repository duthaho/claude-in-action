# Section 07 — MCP

> Status: **coming in v1.1**

The Model Context Protocol lets Claude plug into external tools (databases, APIs, filesystems) with a standard interface. Planned labs:

- `lab-01-filesystem-mcp` — wire up the filesystem MCP server to a docs folder.
- `lab-02-sqlite-mcp` — query a provided `library.db` via the SQLite MCP server.
- `lab-03-custom-mcp-stub` — write a minimal Python MCP server that returns static data.
