# Section 04 — Skills

> Status: **coming in v1.1**

Skills are auto-loading bundles of instructions and resources Claude can pull in on demand. Planned labs:

- `lab-01-first-skill` — build a `changelog-writer` skill that takes unreleased commits and writes a release note.
- `lab-02-skill-with-resources` — ship a skill that reads bundled templates from its own `resources/` directory.
- `lab-03-skill-evaluation` — write eval cases for a skill and measure whether changes regress.
