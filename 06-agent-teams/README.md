# Section 06 — Agent Teams

> Status: **coming in v1.2**

Agent teams are long-lived cooperating agents with shared task lists and messaging — a step beyond ad-hoc subagent dispatch. Planned labs:

- `lab-01-planner-builder-tester` — a three-agent team (planner, builder, tester) working from a feature spec.
- `lab-02-parallel-researchers` — fan-out to N researchers on independent subtopics, merge their findings.
